# Meta Quest 飞行火焰挑战游玩说明

适用场景：`SkyQuest3S.unity`（Meta Quest 3 / 3S）。下面的按键以当前项目中的 `CapeFlightActions.inputactions` 和飞行挑战脚本为准。

## 一局的流程

1. 戴上头显进入游戏，使用左摇杆走向场景中的蓝色起点圆环。角色靠近圆环后挑战自动开始，斗篷能量补满。
2. 在 90 秒内飞过空中的 12 个金色火焰。身体碰到火焰便收集成功，该火焰消失、积分增加 10 分。
3. 头显中的积分提示会显示已收集数量、总分、剩余时间，以及最近一个未收集火焰的方向、距离和上下高度；斗篷扇形图显示剩余飞行能量。
4. 收齐 12 个火焰会提前结算，并按剩余秒数 × 2 加时间奖励；时间耗尽也会结算当前积分。两种结束方式都会把斗篷能量补满。
5. 想再玩一局，离开并重新走进蓝色起点圆环即可。最高分保存在本机。

## Meta Touch 手柄

| 操作 | 按法 |
|---|---|
| 看向目标 | 自然转头 |
| 地面移动与空中前进 | 左摇杆 |
| 转向 | 右摇杆左右拨动 |
| 起飞 / 空中再次上升 | 右手 A 键，每次消耗 1 格斗篷能量 |
| 空中滑翔 | 起飞后自动进入滑翔；左摇杆继续调整飞行方向 |
| 安全停下 | 按下右摇杆 |
| 切换第一 / 第三人称 | 右手 B 键（左握把未按住时） |
| 调整移动速度 | 用右手指向视野右上方速度条，按住右扳机调节，范围 1.0×–4.0× |

挑战只需要触碰火焰，不需要对火焰按扳机。角色落地后可再次按 A 起飞。无论收齐还是超时，结束时斗篷能量都会回满。

本说明根据项目代码和 Unity 场景核对；头显内的实际舒适度与帧率仍需佩戴设备检查。
